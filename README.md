# Simple-Calculator
A clean calculator made with HTML, CSS, and JavaScript. It supports basic arithmetic, percent conversion, delete, clear, mouse input, and keyboard input.
## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla)
